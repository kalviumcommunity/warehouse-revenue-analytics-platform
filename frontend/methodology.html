How this is produced

Data pipeline

Every number on the other pages comes from this pipeline — not hand-typed. Each stage is its own script with its own audit output.

  1. Ingestion — ingest_data.py
    Multi-format CSV/JSON ingestion with delimiter/encoding fallback and JSON flattening.
  2. Intake validation — validate_intake.py
    File existence, format, and schema checks; writes output/intake_report.json.
  3. String cleaning — string_cleaning_pipeline.py
    Trims whitespace, normalizes casing, strips special characters, maps category variants.
  4. Deduplication — deduplicate_data.py
    Exact and near-duplicate removal with a full audit trail of every removed row.
  5. Type enforcement — enforce_types.py
    Dates, currency strings, and booleans cast explicitly; before/after dtype report.
  6. Missing value handling — handle_missing.py
    Drop, median, mode, or forward-fill — each strategy documented with business reasoning.
  7. Outlier detection — outlier_detection.py
    Combined z-score (±3) and IQR (1.5×) flagging — outliers are flagged, never silently dropped.
  8. Profiling — profile_data.py
    Null/duplicate rates, numerical stats, severity-ranked data quality issues.
  9. Feature engineering — feature_engineering.py
    Prep rate, accuracy tier, complaint quartile, and the composite warehouse_health_score.
  10. This dashboard
    Aggregated by assets/generate_fake_data.py into data.js, rendered by app.js.
